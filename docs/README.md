# New World Preservation Project

## Mission
Research and develop a private offline/LAN-compatible
New World: Aeternum environment using legitimately owned
game installations.

## Current progress
- CryPak archive indexing and extraction
- Oodle Kraken decompression
- Datasheet decoding and gameplay database
- NPC and combat catalogs
- Client component-message inventory
- Replication and serialization reconnaissance

## Current research targets
1. Amazon Hub MessageEnvelope
2. ReplicatedStateBundle
3. Javelin ReplicationDataManager
4. GridMate networking architecture
5. Client/server handshake and session initialization

## Rules
- Preserve the original game installation.
- Keep proprietary game binaries and extracted assets out of Git.
- Track original tools, research notes, and reproducible procedures.
- Document verified findings separately from hypotheses.
